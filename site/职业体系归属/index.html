    职业体系归属表（概念归属）¶

    更新时间：2026-11-20

    本文档记录了所有职业所属的魔法体系概念归属，用于跨职业概念对比与验收。遵循核心原则：同一系有两个职业时，先写「概念归属表」再写表——战场级布置（真空/领域/召唤）归远程施法者；自中场域、冲锋、近战附魔、自我化身归近战职业；验收方式是把两职业同环的八条法术并排放，不许有一个概念重复。

    1. 火系¶

    1.1 概念归属表（12 §一·5）¶

    概念类型 裁决官（近战） 诞火者（远程）
    近战电系附魔 / 以身为薪 ✅ 裃决官 ❌ 不归
    近战命中回火 / 火海 / 领域圆心 ✅ 裃决官 ❌ 不归
    召唤链 / 远程火伤 / 持续燃烧 ❌ 不归 ✅ 诞火者
    点燃增幅 / 借火疗愈 / 净化 ❌ 不归 ✅ 诞火者（仅同教）
    宣告定谳 ❌ 不归 ✅ 诞火者

    1.2 已完成法术表¶

    • 裃决官：0-9环，40条，全部近战/自身/近战距离，远程伤害法术 0 条
    • 诞火者：0-9环，40条，全部远程/自身/指定点，近战伤害法术 0 条

    7.2 参考¶

    • 祭祀法术表已完成 0-9环，40条

    设计纪律（12 §一·3、§一·4、§一·5）：

    1. 命名禁止「同名＋后缀」：同一法术线的不同档位必须各有独立名字。
    2. 同一系有两个职业时，先写「概念归属表」再写表：战场级布置归远程施法者；自中场域、冲锋、近战附魔、自我化身归近战职业。
    3. 验收方式：把两职业同环的八条法术并排放，不许有一个概念重复。
    4. 自动化检测抓不到「换皮」：必须人工同环并排比对。
