    2026-11-12 · 第二次讨论：地理骨架与命名体系¶

    用户输入的设定

    • 时代坐标：西方中世纪中晚期；封建制为主，宗教影响力强，同时出现资本主义萌芽。
    • 三大区：中部/东部/北部为帝国；西部为沿海及群岛自由城邦联盟；南部为沙漠与古老文明的遗民。
    • 语言参照：帝国＝英语＋法语；西部＝德语＋西班牙语＋意大利语；南部＝阿拉伯语。

    已定结论

    • 00：世界名定为 卡尔瓦（Carva）；基调＝中世纪末期西欧；核心冲突＝誓约与契约之争（封建誓约 vs 商业契约），定为冲突永动机的"丙案"。
    • 01：冲突永动机倾向 丙为主（无终极反派，价值冲突），待用户确认。
    • 04：单大陆、两山夹一平原；三大区的完整地理与政治结构；气候自洽；咽喉要道；资源分布。
    • 10：建立"一门死祖语＋三分支"的命名体系；完成词根表、音变规则、构词规则、命名禁忌；产出大陆、帝国、联盟、南方共 40 余个地名。

    新增设计洞察

    • 碎岸地形是城邦制的物质基础，不是理想主义（因果而非装饰）。
    • 联盟陆地三面被帝国包围，只靠海——靠海军、钱、帝国分裂存活，形成"谁也赢不了的冷战"。
    • 帝国语的英法混合，最自然解释是一次征服（法语武士贵族征服英语北方）；地名分区因此成为征服史的化石。
    • 南方"很少被深入"＝信息差资产，是资料片与揭示真相的空间。
    • 香料路线：卡斯尔·萨利姆 → 加尔瓦尔山口 → 索尔玛 → 海运全大陆。帝国想绕过联盟修一条陆路，是天然的经济战争引擎。

    新增待决

    2026-11-12 · 第三次讨论：魔法浓度与信仰格局¶

    用户输入的设定

    • 魔法浓度为 中魔：存在体系，但基本不参与工业与生产；只有少数人具备天赋。
    • 帝国：统一的教会统治，信奉唯一主神；一切魔法皆主神赐福；天赋者必须皈依教会并由教会管理；教会只教授圣光魔法；不皈依者或学他系者皆为异端。
    • 联盟：信仰繁杂，核心为七女神——生命（生命系）、海洋（水系）、暴风（气系）、丰饶（自然系）、审判（火系）、勇气（电系）、幸运（占卜与预言类）。各女神各司其职，信众互不冲突。
    • 南方：信仰旧神，具体未知，作为伏笔。
    • 冲突的定义暂缓，改为分模块推进，先做帝国。

    已定结论

    • 07：中魔三条硬约束（不替代人力、不批量复制、不形成产业链）；九系魔法表（圣光＋七系＋旧神未知）；生命与丰饶的边界划分。
    • 06：帝国主神"名讳不可称，只有圣印"；圣光教会；圣裁庭/名录/搜才者/圣所/未录者四机构；联盟七女神与"宽容的裂缝"。
    • 00：宗教格局表；P0-1 基调正式定稿（中世纪末期＋中魔）。

    新增设计洞察

    • 帝国的语言政治：通用语里没有中性的"魔法"一词，只有"恩典"与"亵渎"。当一种东西在语言里没有名字，它就很难被讨论与辩护。
    • "未录者"（不在名录上的天赋者）可作为玩家身份、地下组织名与任务线名。
    • 天赋是随机的，教义却要求它必须皈依 → 教会必然产生"搜才—登记—改造—追捕"的完整链条，也必然产生逃亡者；联盟天然成为避难所。
    • 联盟对帝国的神学反击："一个什么都管的神，是一个什么都管不好的神。"
    • 皇帝称"守冠者"，教宗称"掌灯者"——冠与灯若照不到一处，帝国就裂。
    • 数字结构：一（圣光）＋七（女神）＋？（旧神）→ 可能是九，留作伏笔。

    新增待决

    • P0-7 教会与皇权谁在上（甲双头／乙教权至上／丙教会即国家）
    • P0-8 教会如何解释"非圣光天赋"（甲矫正／乙伪奇迹／丙教义与执行脱节）

    2026-11-12 · 第四次讨论：天赋本体论与生命女神¶

    用户澄清的三点

    1. 幸运女神＝预言（星象、塔罗一类占卜），"语言"确为笔误。
    2. 生命女神的领域扩大到"生"与"死"两端：信徒既可治愈，也可使用衰老、抽取生命等死亡魔法。
    3. 丰饶女神＝自然系，参照 D&D 德鲁伊。
    4. 天赋＝与生俱来的中性魔法能量，无属性；有能量者理论可学任何魔法；帝国因单一信仰只准学圣光。

    已定结论

    • 07：新增"天赋的本体论"整节，确立五条推论——系别是文化非生物学、教会神学更硬也更阴险、异端三来源（走私知识／皈依他神／野法师）、跨系学习可能、"七系是被制度化的七种"。
    • 07：生命系重写为"一系两端"（生／死），确立"她不是善良女神，是边界女神"。
    • 06：七女神表更新；宽容的裂缝重写为三条——审判vs生命（司法权）、自然vs生命（丧葬）、幸运vs审判（占卜）。

    新增设计洞察

    • 野法师是本世界最锋利的设定：他没有"学习"过异端，他只是长成了那样。教会要审判的是一个从未做过选择的人——这是神义论问题，不是法律问题。
    • "天赋中性"反而让教会的神学更硬：属性是"人的选择"，所以正确的选择只有一种；异端不是异类，是选错了的同事。
    • 天赋中性 ⇒ 七系是文化分类，因此历史上必然存在别的分系——为资料片留了"发现新魔法传统"的空间，且不必推翻旧设定。
    • 生命女神的双重性让联盟神系首次获得道德复杂度，"没有一位女神是纯粹善的"。

    新增待决

    • P0-8 收缩为：野法师如何定性
    • P1-19 天赋强弱　P1-20 未受训天赋是否失控　P1-21 预言系的代价

    2026-11-12 · 第五次讨论：天赋的物理行为与帝国政体¶

    用户输入的设定

    1. 未受训的天赋不会成形，只会外溢：能量持续累积、不受控释放纯粹的（无形状的）能量，造成破坏；年龄越大越危险（参照 HP 的默默然）。
    2. 天赋有强弱：先天能量总量不同。
    3. 帝国＝教权至上：皇帝管理世俗、教宗管理宗教；但教会影响力巨大。皇帝与国王须教宗或当地主教加冕；贵族继承须教会承认；教会有绝罚权（剥夺一切头衔与公民身份，交教会审判庭）；教会在帝国内划分主教区，教堂所收捐赠帝国无权征税。

    已定结论

    • 07：新增"天赋的物理行为"——累积、外溢、纯粹能量、年龄递增、泄压、压抑比释放更危险。
    • 07：新增"黑暗闭环"——教会的矫正要求压抑 → 压力升高 → 失控更烈 → 被视为污染证据 → 更严厉矫正。教会正在制造它最害怕的东西，而且是真诚地在制造。
    • 07：提出"施法＝泄压"作为"代价"的候选方案（P0-4）。
    • 08：帝国政体全面落实——权力结构图、教会四项权力、两套地图、五条结构性后果、行政层级草案。
    • 06：教会与皇权定为教权至上；主教区入机构表。

    新增设计洞察

    • 教会的权力是否决权，不是执行力：它能毁灭任何人，却不能治理任何人——这才是"教权至上"容得下皇帝的原因。
    • 教宗之死是帝国最大的政治事件：无人加冕，则一切头衔悬空。皇帝唯一能下的棋是影响"谁当教宗"。
    • 免税＋绝罚＝财政黑洞与敛财工具。帝国缺钱 → 向联盟银行借贷 → 这才是帝国吃不掉联盟的真正原因。没收异端财产是财政收入，但不可写成全员腐败。
    • 两套地图（世俗／主教区）故意不对齐——帝国一切行政混乱、司法冲突与地方割据的源头。
    • 绝罚的效力不均匀：核心区社会性死亡，边疆与北境打折。这个"内部温差"是异端与未录者的生存空间。

    新增待决

    • P1-22 教宗如何产生／谁制约教宗
    • P1-23 历史上有无皇帝被绝罚
    • P1-24 行政层级草案确认

    • P1-26 皇帝本人信不信

    2026-11-12 · 第六次讨论：魔法修订、继业者战争与帝国骨架¶

    用户输入的设定

    1. 魔法修订：不采用"必须不断施法"的方案——那不适合正常运转的社会。改为：能量可被驾驭；未受教导者无法控制，能量累积至爆发；受训者的能量在体内平和循环，产生并积累。
    2. 教宗由枢机团闭门选举，皇帝无法直接干预，但可资助某位枢机。
    3. 继业者战争：一位皇帝死后，新帝想扩权，与教会冲突，被绝罚；所有"有资格者"群起攻之；长年血战后旧帝国崩溃、新帝国崛起，教会毫发无损。
    4. 现任皇帝的家族领地是北方的一个公爵领：山地环绕，矿、煤、林地，出产最精良的甲兵——家族正因此赢得百年前的战争。皇帝直辖该公爵领＋中部首都。
    5. 教宗在帝国境内拥有一座独立城市（参照梵蒂冈），皇帝无权干涉。
    6. 东境王国（奥兰）是帝国唯一的王国级头衔。
    7. 帝国南部贫瘠、人口复杂、黑市走私盛行，设马尔凯边疆区。
    8. 帝国其余部分由大小公爵领与伯爵领构成。

    已定结论

    • 07："天赋的物理行为"改为环流模型（受训＝体内循环；未受训＝无序堆积至爆发）。取消"施法＝泄压"方案。
    • 07：黑暗闭环重写——教会用拒绝教育，证明了自己拒绝教育的理由（自证预言）。
    • 08：帝国骨架全面成型——头衔清单、政治版图、皇权为何"薄"、教会的四项权力与两套地图、教宗国、继业者战争、财政。
    • 03：新增"继业者战争"作为帝国的"零年"，以及"帝位继承"待定项。
    • 04：马尔凯由西界改为南部边疆区；新增伊森霍尔德公爵领、教宗国卢米亚。

    新增设计洞察

    • 重复不是懒，是模板的必然结果。只要一句话能装下所有职业的某类法术，它最终一定会装下所有职业。当一个模板开始跨职业复用时，就该给它加"只有这个职业才有的从句"。

    新增设计洞察

    • "换皮"是自动化检测抓不到的。 同名和逐字同效这两个指标，我第一版全部通过；真正的问题是"同环同四件套、只改一两个词"。这类缺陷只能靠"把两职业同环八条并排放"来抓。
    • 分家的关键不是改法术，是先写概念归属表。 一旦定了"真空归谁"，剩下的替换就只是填空；没定之前，怎么改都会再撞。
    • 近战职业的"场"必须以自己为圆心。 风暴战士保留「风暴领域」这类自中场域是合理的，但"1 英里外的风眼""120 尺外的哨站"必须删——半径的圆心在哪，决定了它是战士还是法师。
    • 后缀命名的真正危害是它让玩家以为有规律。 ·众／·大／·远／·真 读起来像有统一规则，实际上每个都是随手加的。改成风仆→风卫→风将→风王之后，玩家一眼就知道召唤物的位阶——命名系统本身就是玩法说明。

    收尾（同日）：圣言者 6 环「神圣领域·扩展」→「圣言护域」。·扩展 是本轮禁止的同名后缀，且它参照的「神圣领域」是圣武士 4 环的法术（跨职业引用）。至此全库再无「同名＋后缀」，只剩「圣言·抚慰」「圣言·终焉」两个风格前缀。圣言者数值与其余条目一字未动。
