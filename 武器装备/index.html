    武器装备¶

    本文档记录卡尔瓦世界（Carva）中的武器与防具装备，按 D&D 5e 规则体系设定，并按角色等级划分魔法装备。所有数值均为 CRPG 平衡参考值，可用于 12-职业与信仰.md 中的职业装备搭配。

    等级划分：1-4级（初阶）、5-8级（进阶）、9-12级（高阶）、13-16级（大师阶）、17-20级（传说阶）。

    目录（持续更新）¶

    1. 基础武器（简单武器 / 战斗武器）
    2. 基础防具（轻甲 / 中甲 / 重甲 / 盾牌）
    3. 1-4级魔法装备（初阶）——武器、防具、戒指、护身符、药水
    4. 5-8级魔法装备（进阶）——武器、防具、戒指、护身符、药水
    5. 9-12级魔法装备（高阶）——武器、防具、戒指、护身符、药水
    6. 13-16级魔法装备（大师阶）——武器、防具、戒指、护身符、药水
    7. 17-20级魔法装备（传说阶）——武器、防具、戒指、护身符、药水

    装备说明¶

    1. 等级建议：适用等级为推荐最低角色等级，DM 可根据实际情况调整。
    2. 魔法武器攻击加成：所有魔法武器的攻击命中加成包含在表格中，不额外叠加基础属性加成。
    3. 每日激活次数：标注「每日可激活」的能力，在长休后恢复。
    4. 稀有度对照：普通（Common）→ 不常见（Uncommon）→ 稀有（Rare）→ 非常稀有（Very Rare）→ 传说（Legendary）→ 神器（Artifact）。
    5. 货币单位：gp = 金币，sp = 银币，cp = 铜币。
