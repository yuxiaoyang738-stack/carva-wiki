1. 不能替代人力与畜力（种地、运输、锻造靠人和牲口）

## 2. 地理

### 三大区

| 区域 | 归属 | 特征 |
|---|---|---|
| **中／东／北** | 瓦尔德伦帝国 | 中部平原＋北部针叶林，粮仓与道路网 |
| **西部海岸** | 瓦尔玛同盟（自由城邦） | 碎岸地形，良港密布，腹地狭小，群岛 |
| **南部** | 沙漠与纳赫兰遗民 | **巨大的沙漠**、绿洲、香料、旧文明的废墟 |

### 四个节点（核心结构）

> **比例尺的含义**：奥杜恩到奥兰城 950 km，驿马 15 日、商队 38 日。
> **皇帝的命令走到东境要一个月**——所以东境国王在自己领地内近乎独立，
> **不是他野心大，是距离远。** 香料从产地到帝国黑市要走三四个月，**它贵在时间。**

大陆上的货与人只能走这四个点，性质完全不同：

| 节点 | 谁控制 | 能过什么 | 性质 |
|---|---|---|---|
| **瓦尔德丘陵**（帝国↔联盟） | 两边各设一关 | 一切 | **双税走廊**（挡不住，也不该挡） |
| **大沙漠**（帝国↔萨比尔） | 没人控制 | 小队伍·雨季 | **漏** |
| **加尔瓦尔山口**（联盟↔萨比尔） | 联盟重兵 | 大商队 | 唯一的大车队陆路 |
| **索尔玛**（山口北端） | **独立城市** | 香料换手 | **铰链** |

> **索尔玛不是门，是铰链。** 门能被夺走，铰链只能被使用。
> 联盟恨它（本该是联盟的港口），帝国也恨它（多付一层税）——
> **但两边都需要一个中立的换手点，这就是它活下去的理由。**
>
> **帝国的香料有两种价钱**：正规走丘陵（两次关税，贵但稳定）；走私走枯河道（便宜，但要命）。
> 这就是马尔凯人口复杂、黑市盛行、帝国无心管理的物理原因。

| 通路 | 谁控制 | 能过什么 | 性质 |
|---|---|---|---|
| **联盟 ↔ 帝国** | 帝国贵族＋联盟海军 | 一切 | **设卡收钱** |
| **帝国 ↔ 萨比尔** | **没人控制** | 小队伍、雨季、需向导 | **漏** |
| **联盟 ↔ 萨比尔** | 联盟（唯一大车队山口） | 大规模商队 | **垄断** |

> **帝国与萨比尔之间没有山脉**，只有沙。所以帝国的香料不是进口，是**走私**——
> 这就是马尔凯人口复杂、黑市盛行、帝国无心管理的物理原因。
>
> **联盟的垄断有个软肋：漏点在终点。**
> 走私队也到卡斯尔·萨利姆。帝国商人不必绕过联盟，黑市就在联盟的仓库门口。

### 沙漠的来历

**纳赫兰河是内流河**，注入沙漠中央的大湖。文明建在湖上。河死湖干，草原变沙漠。
今天只剩**乌姆·纳赫兰的盐原**与哈拉布的石环。

> 一箭三雕：给沙漠一个**时间点**、给马尔凯的贫瘠一个**原因**（它曾是河谷）、
> 给绿洲一个**来历**（古河道的残余）。
> 也让"沿纳赫兰河道走"变成**沿着一条死去的河的尸骨走**。

### 为什么南方没有海运

缺良港（南岸平滑）＋ 沿途无法补给 ＋ 沿岸强流。
**"无归海"不是地名，是判决。**

### 山川与要道

| 名称 | 位置 | 备注 |
|---|---|---|
| **布兰卡尔山脉** | 北 | "白脊"，东西走向，帝国北屏 |
| **加尔瓦尔山脉** | 西南 | "灰壁"，**东北—西南走向**，联盟与萨比尔之间唯一能过大车队的屏障 |
| **瓦尔德丘陵** | 中西 | **南北向**，帝国与联盟之间。低矮破碎、林密路多——**不是屏障，是走廊** |
| **阿尔让河（Argent）** | 中部 | 母亲河，三支流：维尔、利纳、索兰 |
| **瓦尔德河** | 丘陵 | 自丘陵西流，注入恩格湾 |
| **纳赫兰河** | 南 | **已干涸**的内流河，只在雨季有水 |
| **恩格海峡** | 西部海湾瓶口 | 卡尔哈芬扼守，战时铁链封航 |
| **加尔瓦尔山口** | 山脉中段 | **唯一能过大商队的陆路** |
| **索尔玛** | 山口北端 | **独立城市**——香料出山后的换手点（不是联盟的港口） |

### 海域

**外海／长海**（西）｜**黎明海**（东）｜**灰海**（北）｜**无归海**（南）

### 地理如何解释政治

- **碎岸 → 城邦制**：地形养不起统一的陆上强权，每个海湾都能独立成港。城邦不是理想主义，是地形逼的。
- **平原 → 帝国**：便于道路、骑兵、统一与税收。
- **东西窄 → 纵向治理**：横穿大陆极难，所以南北流动集中在少数几个口子，而"口子"就是一切政治与经济的根源。
- **南境无山 → 无法设防**：没有城墙、没有水、没有产出，只能设不世袭的边侯。**制度是地理逼出来的。**
- **西境有关税、南境没有**：西边贵族抢着守，南边没人去，皇帝只好自己派人。**制度差异是钱推出来的。**

## 3. 帝国：瓦尔德伦

### 一句话

> **教权至上，而皇权"薄"且"脆"**——皇帝拥有最多的合法性、最少的土地，和一座正在枯竭的矿山。

### 基本盘

| 项目 | 内容 |
|---|---|
| 国名 | 瓦尔德伦帝国（The Valdren Empire），*wal-dren*"持冠之国" |
| 性质 | 封建制 ＋ **教权至上** |
| 首都 | **奥杜恩（Aurdun）**，中部偏东，三河交汇，地势平坦，离东境边境不远 |
| 皇冠 | **德伦**——一枚**铁环**，不是金冠。帝国守的是誓，不是富 |
| 皇帝称号 | **守冠者（Crownwarden）** |
| 语言 | 通用语（英语＋法语混合） |

### 皇室：德伦家族

| 项目 | 内容 |
|---|---|
| 姓氏 | **德伦（Dren，"冠"）** |
| 来历 | 家族**原本无姓**。夺得帝位后取了铁环之名——**姓氏与皇位同龄，这本身就是篡位的证据** |
| 现任皇帝 | **埃德蒙三世**（Edmund／宫廷作 Edmond），约 42 岁，德伦王朝第五位皇帝 |
| 名字含义 | *ēad*（财富）+ *mund*（守护）——**"财富的守护者"**（讽刺：他正在失去财富） |
| 信仰 | **真心的虔诚**。不是策略 |
| 性格 | 不残暴，但**已经脏了手** |

### 政治版图

| 区域 | 归属 | 特征 |
|---|---|---|
| **北方 · 伊森霍尔德公爵领** | 皇室世袭 | 山地环绕，铁、煤、林地；主城**卡杜恩（石堡）**；全帝国最精良的甲兵产地——**但矿脉正在枯竭** |
| **中部偏东 · 首都奥杜恩** | 皇室直辖 | 三河交汇，粮仓与道路枢纽 |
| **东部 · 奥兰王国** | 东境国王 | **帝国唯一的王国级头衔**；葡萄、盐、旧贵族；最富也最傲慢 |
| **南部 · 马尔凯边疆区** | 边侯（皇帝任命，不世袭） | 贫瘠、混乱、三教九流、黑市与走私，紧邻南方遗民 |
| **圣座领 · 卢米亚** | 教宗 | **山巅之城**（约 3,000 m），皇帝进不去，也养不活它 |
| **其余** | 大小公爵领、伯爵领 | 皇帝管不到的地方 |

### 皇权的三根支柱

| 支柱 | 内容 | 现状 |
|---|---|---|
| **王冠** | 合法性 | 靠胜利与教会承认，**没有血统依据** |
| **教会** | 加冕 | 必须赴卢米亚，跪在先知的墓前 |
| **铁** | 全帝国最好的甲兵 | ⚠️ **矿山接近枯竭，皇帝在隐瞒** |

### 矿山枯竭 = 一颗叙事时钟

- 不是"皇帝很穷"，而是**"皇帝正在变穷"**。前者是状态，后者是**时限**。
- 他必须同时做三件事：**掩盖、找新矿、弄钱**——每一件都会制造新的敌人。
- 联盟银行家不知道真相，**但闻到了味道**：借得越多、抵押越薄、利率越高。**市场比人先知道。**

### 两套账本（结构性关键）

| 账本 | 管的人 | 知道真相吗 |
|---|---|---|
| **家族账**（伊森霍尔德） | 公爵领财政大臣 | **知道** |
| **帝国账**（奥杜恩内阁） | 帝国财政大臣 | **不知道** |

> **这两个"财政大臣"不是同一个人。**
> 帝国官方预算建立在假数字上，系统没有反馈回路——
> **一旦真相揭开，崩溃不会是渐进的，而是断崖式的。**
> **知道真相的人越少，崩溃就越突然。**

### 谁知道矿快挖完了

皇帝｜公爵领财政大臣｜矿山负责人｜**全体矿工**（明令禁声，管不住嘴者已被"封口"）

> 矿工是一群人，不是一个人。**你封不住一座矿。**
> 而矿枯竭的第一批受害者就是矿工自己——**最先泄密的，一定来自最下面。**

### 帝国财政（已定）

**核心法律：封臣的封臣，不是我的封臣。**
皇帝只向直属封臣收钱；封臣的封臣、商人、自由城邦，他一分也收不到。

| 收入 | 说明 | 现状 |
|---|---|---|
| **领地收入** | 伊森霍尔德与首都周边，唯一不需要任何人同意 | ⚠️ **被矿竭侵蚀** |
| **封建附带权益** | 继承金、助金、监护权、婚姻权、充公 | 稳定，但一次性 |
| **盾牌钱** | 军役四十天折现 | 可用，但削弱军力 |
| **过境税** | 瓦尔德丘陵、三汊、马尔凯路口 | 唯一能碰商人钱袋的口子 |
| **司法罚金** | 领主法庭 | 稳定现金流 |
| **空缺圣职收益** | 主教出缺期间 | 与教会暗战的核心 |
| **借款** | 向联盟银行 | 把未来提前花掉 |

> **皇帝不是不能向全国收税，是无权。** 越过封臣去收钱＝违约，而违约就给了所有人绝罚他的理由。
> **"手头紧"不构成叛国**——所以帝国的政治斗争，大部分发生在账本上，不在战场上。

### 与教会的税收战争

教会免税免的是**捐赠**，不是土地。教会的**主教区**照样要交封建义务。
争夺因此集中在几个**没人需要开口**的地方：

| 皇帝手里 | 教会手里 |
|---|---|
| **主张空缺圣职收益** | **拖延任命**（让收益断流） |
| 主张未成年继承人监护权 | 绝罚（个人） |
| 要求盾牌钱 | 停止圣事（全境，待议） |
| 请求"自愿捐献"（需教宗点头） | 承认另一个人（东境国王） |
| 没收异端财产 | 煽动民众抗税 |
| 把税权包给商人 | **时间** |

> **一个对称**：皇帝手里是刀和账本，教会手里是时间和良心。
> **而皇帝最缺的，正好是时间。**
> **两边都打不到对方真正的钱袋**，这才是这场战争百年无解的原因。

## 4. 教会：帝国正教

### 神

- **名讳不可称。** 只称"**主**"。真名被记为一个符号——"**圣印**"，而非词语。拼读它即为异端。
- 视觉收益：钱币、旗帜、教堂正面，只有那一个印。

### 教会

| 项目 | 内容 |
|---|---|
| 通称 | **帝国正教** |
| 正式名 | 圣光教会（The Church of the Light）／文书名：卢米纳教会（Ecclesia Lumina） |
| 领袖 | 教宗，尊称 **"掌灯者"（The Lantern）** ／"光座" |
| 产生方式 | **枢机团闭门选举**。皇帝无法直接干预，但可以资助某位枢机 |
| 与皇权 | **教权至上**：皇帝管世俗，教宗管灵魂 |

### 四项权力

| 权力 | 内容 | 后果 |
|---|---|---|
| **加冕权** | 皇帝须教宗加冕；国王须当地主教加冕 | 没有加冕，王位就是空位 |
| **承认继承权** | 贵族头衔继承须教会承认 | 教会是**合法性的登记处** |
| **绝罚权** | 剥夺一切头衔与帝国公民身份，交教会审判庭 | 一把不需要军队的刀 |
| **免税权** | 教堂所收捐赠，帝国无权征税 | 永远补不上的财政空洞 |

### 机构

| 机构 | 职能 |
|---|---|
| **圣裁庭** | 异端审判。执行者称**执炬者** |
| **名录** | 所有天赋者的登记册 |
| **搜才者** | 派往各地寻找天赋儿童的人 |
| **启蒙院（The Cradle House）** | **幼年接收机构**。天赋儿童在 3–8 岁初显能量后被送入此处，接受基础教化、语言规范与体内环流训练。入院的第一个仪式是**销名**——剥夺姓氏，此后只有名 |
| **圣所** | 培养／改造天赋者的机构，接收启蒙院结业者。名义上是学校，实质上是**改造所**——把不属于圣光的天赋，"引导"回圣光 |
| **主教区** | 与世俗大区**故意不对齐**——帝国一切司法冲突的源头 |
| **未录者** | 不在名录上的人。法律上不存在；在现实中，他们是逃犯、地下法师、走私者，也是玩家最可能的身份 |

### 天赋儿童的发现与接管（已定）

| 维度 | 帝国正教 | 瓦尔玛同盟 |
|---|---|---|
| **显现年龄** | 约 **三岁**（精灵 5–8、矮人 4–6、兽人 3–4、半血 3–5） | 相同 |
| **父母义务** | **有义务送交**，隐瞒者父母交**世俗司法**审理（非圣裁庭） | **须上报城邦政府**，隐瞒由城邦法院处罚 |
| **搜才者权力** | 可**强制带离**儿童 | 无强制权，仅通报与协助 |

## 5. 魔法

### 天赋：中性的能量

> 天赋是与生俱来的**魔力能量**，**本身没有属性**。有能量者理论上可学任何一系。

| 规则 | 内容 |
|---|---|
| 累积 | 能量随时间自然增长，**年龄越大积得越多** |
| 未受训 | 无法驾驭，无序堆积至临界 → **爆发**（纯粹能量，无形状无方向） |
| 受训 | 经教育建立**体内循环**：平和环流、产生、积累 |
| 强弱 | 先天总量不同；强者涨得更快、更早到临界点 |
| **关键** | 安全与否不取决于"用不用"，而取决于**"有没有人教"** |

### 由天赋推出的五条

1. **系别是文化，不是生物学**——同一股能量，不同的人塑成不同的形状
2. **教会的神学因此更硬**：属性是"人的选择"，正确的选择只有一种。**异端不是异类，是选错了的同事**
3. **异端三来源**：走私的知识／皈依他神／**野法师**
4. **跨系学习可能** → 最危险的异端是会用圣光的叛徒
5. **七系是被制度化的七种，不是全部** → 历史上必有别的分系（资料片入口）

### 黑暗闭环

> 教会用拒绝教育，证明了自己拒绝教育的理由。
> 一个被判定"不可矫正"的孩子被逐出圣所 → 几年后爆发 → 这成了"果然不可矫正"的铁证。
> **而且它是真诚地在制造——没有人在里面使坏。这才是最难写的恶。**

### 魔法的代价（已定 · A+C 混合）

> **施法 ＝ 燃烧生命力 ＋ 累积因果债。** 没有"免费"的法术，只有"还没付账"的法术。

| 代价类型 | 机制 | 具体表现 |
|---|---|---|
| **生命力燃烧** | 1–6 环消耗体力值（短休恢复）；**7 环以上直接扣除「生命力上限」**（不可逆，需魔药／仪式／长休缓慢恢复）；强行升环每多一环额外扣 1 点生命力上限 | 圣光系不消耗生命力，改耗**信仰值**（祈祷、赎罪、什一税可恢复） |
| **因果债累积** | **所有法术无论环数都产生因果债**，随环阶递增；可通过休息、祈祷、偿还仪式、因果任务缓慢偿还 | 达阈值触发**厄运事件**：50% 关键判定自动失败 → 75% 装备掉落／队友判定失败 → 100% **厄运爆发**（BOSS 厄运光环／队友厄运缠身） |
| **气运点** | 消耗 1 点 → **重掷／优势／提升 DC** | **气运＝你偷来的因果，因果债＝DM 手里的厄运牌堆** |
| **野法师** | 无人教导，**因果债双倍累积** | 极易触发厄运爆发——教会证明了自己的理由 |

**圣光系（帝国正教）**：耗信仰值而非生命力，但因果债照常累积；信仰值不足时可烧生命力上限代替。教会宣传"圣光无代价"，现实是**用自由换安全**。

**窥命者例外**：因果债**不是可消耗资源**，不会凭空生成或消失，也不能施加给敌人——他只能把**自己的**因果债转移给盟友或敌人。

| **双向不信任案** | 下院 2/3 通过→上院过半同意即罢免；上院过半通过→下院 2/3 否决则驳回，驳回即终局；每任期各院限一次 |
| **问卦人** | 两院常设，表决前卜问凶吉，结果记录入案并公开宣读，不具否决权 |
| **竞选押金** | 约合熟练工匠一年收入，落选按得票比例退还，得票过低不退 |

### 联盟经济体系（已定）

| 项目 | 内容 |
|---|---|
| 货币 | **海契券**，面额 1/5/10/20/50/100/500，央行垄断发行 |
| 锚定物 | 黄金＋外汇 40%，香料票据 60%（卡尔哈芬商会担保） |
| 央行治理 | 货币政策委员会（MPC）：六城各派一委员，行长列席一票无否决权，4/6 通过 |
| 保险双峰 | 奥兰蒂劳合社（辛迪加制、无限责任、大险）＋ 卡尔哈芬海事保险交易所（股份制有限责任、小险） |
| 皇家口岸规则 | 单次 ≤500 冠，单日 ≤2000 冠，2% 手续费＋官方汇率折价 15–20% |

### 宽容的三条裂缝

1. **审判 vs 生命**：谁有权结束一个人的生命？两套司法权在同一个法庭上撞车
2. **自然 vs 生命**：谁来埋葬死者？两套葬礼，同一条街上的两座神殿
3. **幸运 vs 审判**：占卜算不算逃避裁决？

> **神不敌对，人永远会。**

> 而香料从索尔玛出海后，**第一处能卸货的大码头是克兰茨哈芬**——
> 联盟恨索尔玛的具体理由就在这里：货从它门口过，那段陆路的钱它一分收不到。

## 8. 语言与命名

### 核心思路：一门死祖语，三个活分支

**先民语**已死，只在石碑与祷文里。教会宣称它是"神与人立约的语言"。

| 分支 | 现实参照 | 音变特征 |
|---|---|---|
| **帝国支** | 法语＋英语 | w→v、词尾脱落；北部保留英语式重辅音 |
| **西岸支** | 德语／西班牙语／意大利语 | 保留 w、p→f、直接拼接；南岸与群岛拉丁化 |
| **沙漠支** | 阿拉伯语 | 三辅音词根、喉音化 |

| *wal-* | 持、守、誓、门 | val- | wal-, walt- | wal- |
| *mar-* | 海 | mer- | meer, mar | bahr- |

### 帝国语的英法混合 = 一次征服

> 一批讲法语的武士贵族征服了讲英语的北方，两种语言叠成了通用语。
> **中部是法语式地名（征服者命名），北部保留英语式地名（被征服者的旧地）。**
> **语言本身就是一部征服史。**
