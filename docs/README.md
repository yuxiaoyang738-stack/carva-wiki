# 世界设定圣经 · World Bible

一片封建帝国、一群自由商港与一片干涸的沙漠，正处在旧秩序裂开的那一代——誓言的重量还在，金钱的重量刚刚出现。

---

南北走向的大陆，东西窄如半岛，四面环海。中部平原之上是瓦尔德伦帝国，教权至上，铁冠守着枯竭的矿山；西岸碎岸地带是瓦尔玛同盟，七座城邦以“契”代替“誓”，海契券在良港间流通；南方则是巨大的沙漠，纳赫兰河已干，旧文明只留下半埋的穹顶与沉默的绿洲。

三方交汇处的裂缝，是这片土地不肯安静的原因。帝国说圣光创造世界，联盟说七女神持续维护世界，南方说旧神早于文明——三者各对一侧面，合在一起却不闭环。

没有终极反派，只有互相正确的阵营。你可以是帝国的公民，联盟的商会会籍，或南方回流的迁徙者。你可以偷渡阵营、改变信仰、流动声望；也可以在魔法觉醒那一刻，决定自己属于哪一方。

世界正在裂，而你，正站在裂缝的边缘。
