## 一、这套文档怎么用

1. **从 `00` 读到 `10`**，就是这个世界从一粒种子长成一棵树的过程。
2. **每一章都带一张"必须回答的问题"清单**——那是这一章的工作量，不是装饰。问题清空，这一章才算定稿。
3. **所有未决问题汇总在 `99-待定问题.md`**，随时可以查"我们还没想好什么"。
4. 每次讨论结束，我会更新受影响的章节、更新状态标记、并往 `CHANGELOG.md` 追加一行。

## 四、三条写作纪律

1. **先写"为什么"，再写"是什么"**。没有理由存在的地理、种族、习俗，都是废料。
2. **一切都要能装进 `00` 那一页纸**。装不进去的设定，再漂亮也是旁支。
3. **允许留白**。世界观不需要每一格都填满，未解的谜团是资产，不是欠债——但**必须登记**在 `99`。

## 五、与既有 IP 的边界

- 可以借：位面分层的方法、阵营冲突的社会学、神话纵深的写法、命名系统的严谨性。
- 不可用：被遗忘的国度、艾泽拉斯、中土的具体地名、人名、神名、专有事件。
- D&D 5.1 SRD 的规则文本在 CC-BY-4.0 下可用，但其官方设定宇宙不在其中。
- 本项目的所有名词必须是原创。
