# 卡尔瓦（Carva）

> 旧秩序裂开的那一代——誓言的重量还在，金钱的重量刚刚出现。

这是一个**封建帝国、一群自由商港与一片干涸的沙漠**的世界。

帝国瓦尔德伦守着三河交汇的首都奥杜恩，皇帝称自己为“守冠者”，头戴一枚铁环而非金冠。教权至上，皇权薄如纸，脆如冰。矿山正在枯竭，这不是秘密，只是每个人都装作没看见。

西岸是瓦尔玛同盟——七港同盟，海岸支离破碎，良港密布。这里用“契”代替“誓”，七位女神各司其职，互不敌对。钱第一次比血统更管用，银行、保险、合股、信用凭证在这片碎岸上悄悄生长。

南方是沙漠，纳赫兰河已干，旧文明随河一起消亡。只剩盐原与石环，还有拉哈尔人的商队，沿着一条死去的河的尸骨走，将香料带向北方。

魔法存在，但它不能种地，不能运输，不能锻造。它是中魔的：有天赋门槛，有体系，却不参与工业与生产。教会说一切魔法皆神赐，只有“恩典”是正当的；其余皆为异端。异端不是异类，只是选错了的同事。

世界在变。旧的誓约正在松动，新的契约尚未站稳。教会与帝国争税收，帝国与联盟争关税，商港与沙漠争水源。每个阵营都自认为正确，每个真相都只说了一半。

这是中世纪末期，一个看起来一切如常、实际处处在裂的时代。
