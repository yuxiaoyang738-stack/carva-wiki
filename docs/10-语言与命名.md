## 一、核心思路：一门死去的祖语，三个活着的分支

我们不造三套互不相关的语言，而是造**一门先民语（The Old Speech）**，让它分裂成三支。这样：

- 三个文明的地名会**共享词根但音变不同**，听起来像同一个世界长出来的；
- 玩家会隐约感到"这些名字好像有关系"，但说不出为什么——**这就是可信度**；
- 我们以后造任何新地名，都有机械规则可循，不会越写越散。

**先民语的地位**：已死，只在石碑与祷文里。教会宣称它是"神与人立约的语言"，因此读它等于触碰神权——这给了它宗教与政治的重量。

## 二、三分支与音变

| 分支 | 现实参照 | 使用者 | 音变特征 |
|---|---|---|---|
| **帝国支** | 法语 + 英语 | 瓦尔德伦帝国 | w→v（*wal→val*）、词尾失落、元音前移；北部保留英语式重辅音 |
| **西岸支** | 德语 / 西班牙语 / 意大利语 | 瓦尔玛同盟 | 保留 w、p→f（*vel→feld*）、复合词直接拼接；南岸与群岛受拉丁化影响，词尾加 -a/-o |
| **沙漠支** | 阿拉伯语 | 拉哈尔人 | 三辅音词根制、喉音化（k→h）、"海"作 *bahr*、"塔"作 *burj* |

> **帝国语的"英法混合"不是随机的**——最自然的解释是**征服**：一批讲法语的武士贵族征服了讲英语的北方，两种语言叠在一起成了通用语。所以帝国中部是法语式地名（征服者命名），北部保留英语式地名（被征服者的旧地），交界处出现双语叠加的名字。**语言本身就是一部征服史。**

## 四、构词规则

1. **帝国支**：`修饰词根 + 核心词根`，重音在前，词尾常脱落。
   *kar + dun* → **Cardun**（石堡）→ 中译"卡杜恩"。
2. **西岸支**：直接拼接，不插入连接元音。
   *kar + hafen* → **Karlhafen**（石港）。南岸与群岛化：*sol + mar* → **Solmar**（日海）。
3. **沙漠支**：三辅音词根 + 派生模式，修饰语用 *al-*（定冠）或直接并置。
   *qasr + nahr* → **Qasr Nahran**（河上之宫）。
4. **命名禁忌**：西岸支不出现 *th-*；沙漠支不出现 *-burg / -stein*；帝国支的北部不出现 *-a* 结尾的拉丁化词尾。**破例 = 廉价。**

## 五、语言清单

| 语言 | 使用者 | 地位 |
|---|---|---|
| **先民语** | 无人（仅学者与教士） | 死语，神圣 |
| **通用语（Common）** | 帝国全境 | 官方语言，学者称 *Lingua Valdrensis* |
| **北岸话** | 联盟北部 | 商贸与造船 |
| **索兰诺话** | 联盟南岸 | 与沙漠贸易的接触语 |
| **伊索拉诺话** | 斯佩扎群岛 | 银行、保险、海商法 |
| **拉哈尔语** | 南部沙漠 | 游牧与香料商队 |
| **古沙语** | 纳赫兰遗民祭司 | 死语，石碑上 |

> **语言政治**：帝国从不禁止地方语言，但**只承认通用语的法律效力**。签契约、上法庭、进教会学校，都得用帝国语。西岸商人因此发明了"双契约"——一份帝国语给税吏看，一份本地方言给自己人看。这类细节比任何宏大叙事都更能让世界活起来。

## 六、命名成果（已定）

### 大陆 · 一陆三名

| 使用者 | 名称 | 语源 | 含义 |
|---|---|---|---|
| 帝国官方 | **卡尔瓦（Carva）** | *kar-wal* 石之持守 | "持守之石"，附会为"大地之冠" |
| 西岸 | **马尔卡（Marka）** | *mar-* + *-ka* | "海之岸" |
| 南部 | **哈瓦尔（Harwal）** | *khar-wal* | "立世之石"，他们认为世界从这块石头上长出来 |

> 一陆三名本身就是世界观：**没有人拥有这片土地的命名权**。

### 帝国

| 类型 | 名称 | 语源 | 含义 |
|---|---|---|---|
| 国名 | **瓦尔德伦（Valdren）** | *wal-dren* 持冠 | "持冠之国" |
| 皇朝 | **德伦家族（House Dren）** | *dren* 冠 | 皇冠"德伦"是一枚**铁环**，不是金冠——帝国守的是誓，不是富 |
| 皇帝称号 | **守冠者（The Crownwarden）**，简称 **瓦尔德（Vald）** | *wal-* | 不是"王"，是"守" |
| 皇都 | **卡杜恩（Cardun）** | *kar-dun* 石堡 | 起于一座河汊间的石堡，长成世界的中心 |
| 东部大区 | **奥兰（Auren）** | *aur-* 金/晨光 | 双关：日出的地方，也是金子的地方 |
| 北部大区 | **布兰诺（Branno）** | *bran-* 白 | 帝国语给古英语旧名"布兰"加了 -o 后缀——征服的痕迹 |
| 西部边疆 | **马尔凯（Marche）** | 边疆 | 驻军区，走私者的天堂 |
| 南部边疆 | **加尔瓦尔（Garwal）** | *ghar-wal* 空之守 | 边境混血地名，帝国支与沙漠支的交界 |
