## 一、同盟：六个城邦，一个名字

| 项目 | 内容 |
|---|---|
| 正式名 | **瓦尔玛同盟（The Walmar League）**，*wal-mar* 持海 |
| 俗称 | **七港同盟**（建盟时七港，第七港已失，今存六个；见 [03](03-历史与纪元.md)、[99](99-待定问题.md) P1-42） |
| 性质 | **松散的商业同盟**：共同防御、共同关税、共同航道，**各城自治** |
| 成员 | 卡尔哈芬、瓦尔登施泰因、克兰茨哈芬、加维拉、卡萨维拉、奥兰蒂 |
| 非成员 | **索尔玛**——独立城市，不属于任何一方（铰链） |
| 命脉 | 恩格海峡（卡尔哈芬扼守，战时铁链封航） |
| 信仰 | 七女神，宽容 |
| 自称 | **自由民（Freemen）**——一个政治身份，不是民族身份 |

> **同盟不是一个国家。** 它没有首都、没有共同君主、没有统一的常备军。
> 它有的是一份契约、一支联合舰队、一套共同关税，和六个各自说着不同方言的议事厅。

## 二、政体：议会共和制

### 1. 权力结构总览

```
                 ┌─────────────────┐
                 │   公民大会        │  全员成年公民，唯一职能：选举
                 │  （Citizen      │  无财富门槛
                 │    Assembly）   │  ★ 不能立法、不能表决议案
                 └────────┬────────┘
                          │ 选出
                 ┌────────▼────────┐
                 │   城邦领袖        │  任期 5 年，可无限连任
                 │ （可被不信任案罢免）│  普通行政政策可直接实施
                 └────────┬────────┘
                          │ 提交议案
        ┌─────────────────┴─────────────────┐
        │                                   │
┌───────▼────────┐                  ┌───────▼────────┐
│   上议院        │  过半数可否决     │   下议院        │
│ （Upper House） │─────────────────▶│ （Lower House） │
│ 财富门槛        │  下议院 2/3 可反否决│ 任何成年公民    │
│ 富商/公会/贵族/  │◀─────────────────│ 皆可竞选        │
│ 名流            │                  │                │
└────────────────┘                  └────────────────┘
```

### 2. 三大机关

| 机关 | 产生方式 | 门槛 | 核心权力 |
|---|---|---|---|
| **公民大会** | 全体成年公民 | **无财富门槛** | **只做一件事：选举城邦领袖**。不立法、不表决议案、不罢免 |
| **上议院** | 由符合资格者充任 | **财富门槛**：富商、公会领袖、城邦贵族、社会名流 | 高级立法与审议；可否决下议院议案；可提不信任案；重大议案 2/3 可绕过下议院 |
| **下议院** | 任何成年公民竞选产生 | **无门槛** | 普通立法；可以 2/3 反否决上议院；可提不信任案 |

> **公民大会的设定是刻意的。** 让每个自由人都有票，但只给你一张**五年用一次、且只能选人不能选法案**的票。
> 联盟人会说：这才是共和——人民选主人，主人治国。
> 帝国的观察者会说：这是一场每五年上演一次的加冕礼，只不过皇冠是花钱买的。

### 3. 城邦领袖

| 项目 | 内容 |
|---|---|
| 产生 | **公民大会投票选出** |
| 任期 | **5 年** |
| 连任 | **无限制** |
| 权力边界 | 见下方"三条表决路径" |
| 被罢免 | 只能通过**不信任案**（见第四节）；不可被公民大会直接罢免 |

### 4. 三条表决路径（制度的心脏）

领袖提出议案后，走向由**上议院**的表现决定：

| 路径 | 条件 | 结果 |
|---|---|---|
| **甲 · 寡头通行** | 上议院 **≥ 2/3** 通过 | **无需下议院批准**，直接通过 |
| **乙 · 联席裁决** | 上议院 **未达 2/3** | 交**上下两院联席表决**，**超过半数**赞成即通过 |
| **丙 · 普通行政** | 普通行政政策（非加税／司法改革／财政计划） | **无需任何表决**，领袖可直接实施 |

> **这三条路径就是全部政治。**
> 想绕过下议院，先凑到寡头的 2/3；凑不到，就得回下议院数人头。
> **而"普通行政政策可直接实施"这一条，是领袖真正的权力缝隙**——什么叫"普通"，由谁界定，是一辈子的争讼。

### 5. 两院的相互否决（镜像对称）

| 情形 | 门槛 | 备注 |
|---|---|---|
| 上议院否决下议院议案 | **过半数** | 上议院占优 |
| 下议院反否决 | **2/3** | 下议院自保 |
| 下议院否决上议院议案 | **2/3** | 下议院占优（对称） |
| 上议院反否决 | **过半数** | 上议院自保（对称） |

> **两边都能赢，但赢的场合不同。**
> 上议院赢在日常与多数场合；下议院赢在**民意沸腾到 2/3 的那一刻**。
> 这套设计真正的作用是：**让寡头在平时畅通无阻，让民众在极端时留有爆发口。**

### 6. 表决计数与法定人数（已定）

| 项目 | 规定 |
|---|---|
| 计数基数 | **以出席议员为基数**（不是全体议员） |
| 法定人数 | **须有过半议员出席**方可开会与表决 |
| 弃权 | 计入出席，不计入有效票 |

> **这条算术决定了政治斗争的形式。**
> 因为以出席为基数，**"让对手不到场"就成了最便宜的战术**——马车坏在路上、会议提前一天、投票改在下雨天。
> 因为有过半法定人数，**"把会开不成"就成了最有力的拖延**。
> 联盟的议会斗争因此极少在讲台上发生，多在日程表上发生。

## 三、上议院的财富门槛：合法的不平等

### 1. 谁有资格

| 类别 | 说明 |
|---|---|
| **富商** | 资本与贸易额达标者 |
| **公会领袖** | 行会、商会、船东公会的当家人 |
| **城邦贵族** | 联盟没有帝国式封建贵族，这里的"贵族"是**世代富商与世袭官职家族** |
| **社会名流** | 学者、名医、大建筑师、有声望的艺术家——**这一类是门槛上的一道人情缝** |

### 2. 这道门槛为什么不显得难看

> **规则从不说"富人更尊贵"，只说"上议院有财产要求"。**
> 财产要求是一个客观数字，人人可以查，人人可以达。
> 于是歧视被翻译成了**能力问题**：你进不去，是因为你赚得不够。

这就是联盟最高级的那种不公平——**它甚至不认为自己不公平。**

### 3. 门槛由谁定？（宪章机制）

财产门槛写进**城邦宪章**，不由普通立法决定。修改宪章需：

1. 上下两院各自 **2/3** 通过；
2. 且须**守护神殿祭司见证**（七女神中该城的主保女神）；
3. 且须**同盟其他城邦书面认可**。

> **这三道锁，等于让既得利益者给自己上锁。**
> 现实中寡头绝不会主动降低自己的门槛——所以这条宪章在历史上只被修改过极少的次数，
> 而每一次修改，都伴随一场城邦内部的流血或一场同盟危机。

### 4. 非正式的权力：比正式规则更强

上议院议员真正的力量不在票数，而在**对下议员的实际影响力**：

| 手段 | 说明 |
|---|---|
| **钱** | 竞选经费、债务、码头工的工资、船东的订单 |
| **工作** | 下议员多是小商人、匠师、船副——他们都是上议员们的雇员或债务人 |
| **信息** | 远洋消息、汇率、粮价，只有商会先知道 |
| **议程** | 什么时候开会、投什么、投多久——都在上议院手里 |

> **上议院不需要买票，它只需要让人"恰好"在投票日不在城里。**

## 四、不信任案（罢免机制）

### 1. 双向提案

| 提出方 | 本院表决门槛 | 交对方 | 对方表决 | 结果 |
|---|---|---|---|---|
| **下议院** | **2/3** 通过 | 上议院 | **过半数** 同意 | 罢免成立；未过半则驳回，**下议院不得再反驳回** |
| **上议院** | **过半数** 通过 | 下议院 | **2/3** 否决则驳回 | 否则通过；**上议院不得再反驳回** |

> **两侧不对称，而且方向是明确的：上议院这条路是主路，下议院那条是窄门。**
>
> **上议院发动的不信任案，明显更容易得手。**
> 理由只有一条，但它是决定性的：**下议院需要 2/3 多数才能挡下它。**
> 而上议员只要有过半数不满，案子就已经出去了；下议院若要否决，就必须凑齐三分之二——**在任何一个正常任期内，凑齐 2/3 的"全体保护领袖"共识，几乎不会发生。**
>
> 反向看，下议院的案子更难：它自己要凑 2/3 才能发动，而发动后只需要上议院过半数就放行。
> 也就是说，**下议院不仅要证明"我们愤怒"，还要证明"我们愤怒得足够整齐"**。
>
> > **换言之：寡头罢免领袖是常态操作，平民罢免领袖是政治地震。**
> > **而这正是这套制度的真意——罢免的大门是朝着上流社会开的。**

**必须写进正文的结论**：

> **在联盟的议会共和制下，城邦领袖的每一个决定，天然地更偏向"上流社会"的利益。**
> 这不是因为领袖贪婪，而是因为**他的职位能不能保住，主要取决于上议院那半数人**，
> 而下议院只有在极端时刻（2/3 一齐反对）才构成真正的威胁。
> **制度不需要收买领袖，它只需要让领袖算得清账。**

### 2. 次数限制

> **每一任期，上议院与下议院各有一次提出不信任案的机会。**

**这条限制的用意（写作时不要软化）**：

- 它保护领袖——一旦某一院的机会用掉并被驳回，这一任再无手段。
- 它保护制度——不信任案不是党争工具，是一次性的"核选项"。
- 它制造剧本——**"这一次机会，要不要现在用？"** 本身就是一个每一任都会发生的悬念。

### 3. 程序纪律

| 规则 | 内容 |
|---|---|
| 排他 | 同一任期内，一院的不信任案在表决终结前，另一院不得另提 |
| 不可反驳回 | 驳回即为终局，不得再启 |
| 罢免后果 | 罢免成立后**尽快召开公民大会**，选出新的城邦领袖 |
| 随任制 | 领袖任命的官员**随领袖一同去职**，由新领袖重组 |

### 4. 一个结构性的剧本（必写进写作指南）

因为**上议院过半数**即可通过不信任案，而领袖的重大议案要**上议院 2/3**才能绕过下议院：

> **上议院可以先否决领袖的议案，再顺势提出不信任案——两道门都用同一把钥匙开。**
> **领袖在寡头面前是脆的，在平民面前反而是稳的。**

这解释了一个看起来奇怪的现象：**联盟的领袖总是先讨好富人，而不是先讨好民众。**
不是因为他不爱人民，是因为**只要上议院半数人不满意，他的位子明天就空了；而下议院要凑到 2/3 才能动他——那几乎不可能。**

> **于是联盟出现一种奇特的政治气候：**
> 领袖对码头工人的请愿可以点头、可以拖延、可以说"我一定想办法"——因为工人只有一张五年一次的选票。
> 但对商会的一份备忘录，他必须当天回复——**因为那半数议员明天就可能开会。**

## 五、同盟层：六个城邦怎么一起做决定

同盟只处理三件事：**共同防御、共同关税、共同航道**。其余全部归各城自治。

### 同盟议事会的表决方式（混合制）

| 议题类型 | 表决方式 | 原因 |
|---|---|---|
| **外交** | **一城一票** | 主权平等，小城也需要面子与尊严 |
| **司法争议** | **一城一票** | 判例不可被资本加权 |
| **军费分摊** | **按出资配额加权** | 谁出钱谁说话，卡尔哈芬的舰队不是白给的 |
| **关税与航道** | **按贸易额加权** | 同样，钱在哪，票就在哪 |

> **混合制不是妥协，是精确的分赃。**
> 联盟用"一城一票"保住了体面，用"按配额加权"保住了现实。
> 而这套双轨制制造了无穷的扯皮空间——**换议题就等于换规则，于是"某个问题该归哪一类"成了联盟最激烈的争论。**

### 同盟议事会的席位与频率

| 项目 | 内容 |
|---|---|
| **常会频率** | **五年一次**（正好卡在城邦领袖任期内，每届领袖至少主持/出席一次） |
| **主办城市** | **六城轮流主办**（体面上平等，实则每届主办方在议程设置、接待规格、后勤安排上拥有隐性议程权） |
| **紧急会议** | 遇天灾、战争、重大危机等，经任意两城领袖联名请求，或六港常务局提议，经三城以上响应即可召集 |
| **地点** | 轮流主办城的议事厅；日常工作由**六港常务局**承接 |
| **与会者** | 各城领袖 + 各城上议院推举的代表 |
| **决议效力** | 对成员城邦有约束力，但**各城可保留"违宪审查"式的拒绝权**（见待定） |

---

### 六港常务局（The Six-Port Bureau）

**地位**：同盟唯一的常设行政与联络机构，常驻卡尔哈芬（恩格海峡北岸，联盟实际主导者所在）。

**名称由来**：*seis-puertos*（六港）+ *bureau*（局/办公桌）——直白、行政化、显得枯燥无害，是最好的伪装。

**核心职能**：

| 职能 | 说明 |
|---|---|
| **日常联络** | 六城大使、联络官常驻办公，处理城邦间日常沟通、议题商谈、普通矛盾纠纷；领袖意见由派遣官员沟通商议、最终敲定 |
| **议程筹备** | 为五年常会与紧急会议准备议程、背景文件、法律意见、财政测算 |
| **情报汇聚** | 六城大使、商会情报员、联盟官员混在一起，卡尔哈芬因此成全联盟的“听风台” |
| **档案与契约** | 保管同盟条约、关税协定、航道规则、历届决议原文 |
| **后勤与安保** | 为常会、紧急会议提供场地、通译、安保、后勤保障 |

**人员制（混合任期制）**：

| 类别 | 任期 | 说明 |
|---|---|---|
| **大使** | **随领袖任期（五年一换）** | 政治忠诚优先，领袖换人全换 |
| **技术官员、法律顾问、档案员、翻译、安保、杂役** | **长任期（10–15 年，跨领袖任期）** | 专业连续性优先，形成“常驻官比领袖更懂规则”的结构性倒挂 |

**经费分担**：

| 项目 | 承担方 |
|---|---|
| 各大使馆的人员薪俸、活动经费、日常开销 | **所属城邦**自行承担 |
| 六港常务局的**建筑维护、日常杂役仆人、普通工作人员薪资、安保人员、水井疏浚、灯油补给、物业管事等杂项开支** | **由东道主卡尔哈芬自愿承担** |

> **卡尔哈芬的结构性优势（必写进写作指南）：**
> 机构设在自家门口，卡尔哈芬天然掌握“谁见了谁、什么时候见、文件改过几版、谁先看到情报”的元数据。
> 卡尔哈芬不需要插手表决，它只需要**让人“恰好”在关键时刻看到关键文件、在关键会议前“恰好”收到关键情报**。
> 这比显性表决权更可怕，也是联盟“看似无害实则控制”风格的极致体现。

## 六、公民权：谁算"自由民"

### 1. 三档身份

| 身份 | 帝国 | 联盟 |
|---|---|---|
| **完整公民** | 帝国公民（人类为主） | **自由民**：可入公民大会投票、可竞选下议院、可竞选城邦领袖 |
| **受限公民** | — | **精灵与矮人**：有公民权，但**不得进入上议院**、**不得参与公民大会投票**、**不得竞选城邦领袖** |
| **居民** | 精灵与矮人：仅有居住权 | 外国侨民、南方遗民（限索尔玛、马尔凯） |

### 2. 精灵与矮人的处境

| 项目 | 内容 |
|---|---|
| 信仰 | **允许信仰七女神**（帝国不许） |
| 社会氛围 | 联盟人对精灵矮人的偏见明显少于帝国人 |
| 政治权利 | **不能进上议院**（明文规定，不是财产门槛的自然结果） |
| 投票权 | **不能参加公民大会、不能选城邦领袖** |
| 结论 | **联盟比帝国宽容，但宽容有明确的天花板** |

> **这条天花板写得很明白：联盟愿意让你信什么，但不愿意让你决定谁来统治。**
> 它比帝国体面——帝国连信都不许你信；
> 但它和帝国分享了同一个前提：**你不是我们的人。**

**一个必须承认的写作后果**：联盟自我叙述的"自由"因此有了裂痕。精灵与矮人在联盟能做买卖、能请律师、能入公会、能买船——**就是不能投票**。这个矛盾不用解决，它是联盟最好的剧情燃料。

## 七、两个制度化的细节（已定，来自七女神信仰）

### 1. 问卦人（The Diviner）

已定设定里，幸运女神信徒的社会职能是"**议会的问卦人**"。这里把它制度化：

| 项目 | 内容 |
|---|---|
| 位置 | 两院议事厅各有**常设问卦人**，由幸运女神教团推举、城邦领袖任命 |
| 职责 | 重大议案表决前，观星、抽签或掷筹，卜问凶吉 |
| 结果 | **记录入案，且必须公开宣读** |
| 效力 | **不具否决权，只有记录与宣读的义务** |

> **它没有法律效力，这才是它最有用的地方。**
>
> **用法一 · 拖延**："卜象不明，此事宜缓议。"——完全合乎制度，完全无法反驳，可以把一个议案拖到明年。
> **用法二 · 施压**：问卦人可以"恰好"卜出对领袖不利的结果，于是这张纸成了寡头不必亲自出手的刀。
> **用法三 · 阻断**：如果某议案触怒了两院，问卦结果公开宣读后，异议者可以理直气壮地说"连天都不许"。

**与帝国的对照（写作时可用）**：

| | 帝国 | 联盟 |
|---|---|---|
| 神如何干预政治 | 教宗的**绝罚**：剥夺合法性，是硬刀 | 问卦人的**卜象**：记录与宣读，是软刀 |
| 效果 | 一刀下去，王位变空位 | 一句话下去，议案变"明年再说" |

> **帝国用神学决定谁不能当皇帝；联盟用占卜决定什么议案不能今年通过。**
> 一个是审判，一个是天气。

### 2. 押金制度（Deposit）

竞选公职须先缴纳**押金（Deposit）**。

| 项目 | 内容 |
|---|---|
| 金额 | 按城邦与职级不同，约相当于**一个熟练工匠一年的收入**（具体数字待定，见 [09](09-经济与贸易.md) 物价章） |
| 退还 | 落选者按得票比例退还；得票过低者**不予退还** |
| 作用 | **不设明文歧视，却把穷人挡在门外** |

> **它比财产门槛更阴险，因为它在字面上对所有人开放。**
> 你想参选？可以。先交钱。
> 而一个能拿出一年收入的码头工人，已经是码头工人里最富的那一个了。

## 八、这套制度的自我叙述

联盟人怎么解释自己的制度？三句标准说法：

1. **"我们选我们的主人。"**——公民大会。人人有票，人人平等。
2. **"会开船的人管船。"**——上议院。钱与经验不该被人数淹没。
3. **"神看着我们投票。"**——问卦人。制度里有一处不属于人的位置。

而这三句话各自都有它的反面：

1. 人人有票，但**票只能选人，不能选事**。
2. 会开船的人管船，**所以船永远归他们**。
3. 神看着我们投票，**但读神意的人是幸运女神的祭司，而祭司的香火钱来自上议员。**

> **他们说的是真的，只是不完整。**
> 这就是这个世界最重要的写作纪律：**一个制度不需要撒谎才能骗人。**

## 八、银行与保险体系

### 一、联盟货币：海契券

**名称**：**海契券**，*Pactum Maris*（拉丁化），意为「海上契约的凭证」。

**面额**：1 / 5 / 10 / 20 / 50 / 100 / 500（七档），满足从市井买卖到大宗贸易的全场景。

**性质**：**法定货币、强制通用、无限法偿**。联盟六城邦全境强制流通，私人拒收者视为违反《同盟契约》。

| 属性 | 内容 |
|---|---|
| **发行主体** | **奥兰蒂央行**（联盟央行，唯一发行机构） |
| **发行形式** | 统一券，央行垄断发行，各城邦商业银行不得自行印刷 |
| **锚定物** | **混合锚定**：央行资产表中「黄金+外汇储备」占 40%，「优质商业票据（香料预售合同、船运保单、港口仓单）」占 60% |
| **发行管控** | 央行货币政策委员会（MPC）每季度审议发行上限，按「香料贸易顺差预期 + 清算需求」核定 |
| **兑换承诺** | **无金属兑换承诺**（纯信用货币），央行承诺维持清算纪律、控制发行节奏 |

> **香料是货币的影子**。央行资产表里 60% 的商业票据以香料预售合同为核心，**香料价格波动直接传导到货币发行上限**。香料商会因此成为「隐形央行」——谁掌握香料定价权，谁就掌握货币发行上限。

### 二、奥兰蒂央行：联盟的「法兰克福」

#### 1. 双重身份与治理结构

奥兰蒂央行同时承担 **央行职能**（发行、清算、最后贷款人、货币政策）与 **清算中心职能**（跨城结算、风险监控）。

为防止「奥兰蒂城邦利益绑架央行」，采用 **联盟货币政策委员会（MPC）** 制：

| 机制 | 内容 |
|---|---|
| **组成** | 六城邦各派一名委员（任期 5 年，可连任一次），奥兰蒂行长列席、有一票、无否决权 |
| **决策门槛** | 货币政策（发行上限、基准利率、准备金率）需 **4/6 通过** |
| **商业业务隔离** | 行长不参与商业贷款审批；央行不直接经营商业存贷，商业银行单独设立 |
| **透明义务** | 每季度公布资产表、发行量、清算余额；资产表中「香料预售合同」由卡尔哈芬商会担保 |

### 四、货币政策工具：部分准备金制 + 香料票据回购

| 工具 | 当前参数 | 说明 |
|---|---|---|
| **法定准备金率** | **1/5（20%）** | 商业银行存款 20% 必须存放央行，不计息 |

### 五、汇率体系与皇家口岸：帝国的隐形税收

#### 1. 双轨汇率制

| 汇率类型 | 定价机制 | 当前水平（示例） |
|---|---|---|
| **官方汇率** | 帝国皇家金库每月公布「法定兑换比价」 | 1 冠 = 8.5 海契券（故意低于市场价 15–20%） |
| **黑市汇率** | 卡尔哈芬「汇率广场」每日公开报价，参考 KCB、OCB、主要商会成交均价 | 1 冠 = 10.2 海契券（市场供需决定） |

#### 2. 皇家口岸

帝国在边境口岸（瓦尔德丘陵、马尔凯）设立**皇家口岸**，归皇家金库直属，垄断官方兑换。

| 规则 | 内容 |
|---|---|
| **兑换限额** | 单次 ≤ 500 冠（约 4,250 海契券），单人单日 ≤ 2,000 冠 |
| **手续费** | 2% 手续费 + 官方汇率折价（15–20%）= 实质税率 17–22% |
| **拒兑条款** | 币面磨损、污损、残缺、或经非皇家鉴定机构鉴定为伪币者，概不兑换 |
| **运作实态** | 官方渠道「买难卖易」：帝国商人买联盟券易（按官方汇率），卖联盟券难（限额、拒兑、排队） |

#### 3. 黑市套利闭环

> **帝国商人反而更信「敌国」纸币**——随着皇室矿脉枯竭、皇家金库偷偷降低金冠成色，帝国黑市出现「逆向格雷欣法则」：
>
> - **劣币（低成色金冠）驱逐良币（高成色金冠）流出市场**
> - **良币（海契券）反而成为黑市硬通货**，黑市汇率长期高于官方汇率 15–20%
> - **皇家口岸秘密派人去黑市高价收海契券**——帝国官方机构在自家黑市买「敌国」货币，以偿付外债、维持储备
> - **卡尔哈芬商会早已看穿**：「皇帝用税收买我们的纸币，再拿纸币去黑市换我们的纸币，最后还得求我们别一次性兑现太多」

**套利闭环数学**：
```
联盟商人带 1000 海契券
→ 黑市换 98 冠（汇率 10.2）
→ 帝国官方市场买货，卖 120 冠（利润率 22%）
→ 回联盟官方渠道换 1020 海契券（汇率 8.5，手续费 2%）
净赚：20 海契券（2%），扣除运输、贿赂、时间成本 → 仅大商会可跑通
```
→ **大商会垄断跨境套利，小商人只能去官方渠道被收割** → 阶级分层固化。

### 六、保险体系：劳合社与海事保险交易所双峰并峙

#### 1. 奥兰蒂劳合社——无限责任的「大险」中心

### 七、三角博弈：央行—皇家金库—教会

| 维度 | 帝国皇家金库 | 联盟央行（奥兰蒂） | 教会（帝国正教） |
|---|---|---|---|
| **发钞权** | 垄断金冠铸造，不发纸币 | 垄断海契券发行，统一券 | 无 |
| **利率管制** | 受教会限制（高利贷罪） | 商业利率公开，风险定价 | 解释「高利贷」定义，垄断合法利率上限 |
| **跨境流动** | 禁止海契券在帝国官方市场流通 | 海契券在联盟全境强制通用 | 视海契券为「异教货币」，禁教士持有 |
| **核心冲突** | 皇帝向联盟借钱 → 税权抵押给联盟银行 | 持有帝国税权债权，影响帝国财政 | 试图派「利率稽察使」入联盟港口，被以「契约自由」拒绝 |

> **三角博弈的核心**：皇帝需要钱 → 借联盟钱 → 税权抵押给联盟 → 联盟银行成帝国债主 → 教会试图干预利率 → 联盟以「契约自由」拒绝 → 皇帝夹在中间。

## 十、写作纪律（本体系）

1. **货币不是中性的**。海契券的发行、锚定、流通，每一步都刻着「香料—航运—信用」的利益链条。
2. **央行不是圣人**。MPC 委员会的投票记录、利益披露、私下交易，都是剧情钩子。
3. **汇率是武器**。皇家口岸的拒兑条款、黑市汇率的每日波动、套利闭环的数学检验，都能写成具体的商战场景。
4. **保险是赌局**。劳合社 Names 把家族性命押在航线上；交易所的精算模型里藏着「不愿让玩家知道的死亡率」。
4. **玩家能做的事**：在汇率广场做套利、替商会押运香料票据、在劳合社当 Names 押一条航线、帮黑市商人洗海契券、查央行行长的私账。**如果这些都不能做，这一章就是废纸。**

## 九、与帝国的结构性对照（本章的价值在这里）

| 维度 | 帝国 | 联盟 |
|---|---|---|
| 合法性来源 | **神授**（加冕） | **选票**（公民大会） |
| 最高权力 | 皇帝（受教会制约） | 城邦领袖（受上议院制约） |
| 罢免的实际难度 | 绝罚一次，即合法性归零 | **寡头过半即可动，平民需 2/3 才能保** |
| 财富进入政治的通道 | **封地、封建义务、包税制** | **上议院席位、押金、竞选经费** |
| 不平等的形式 | **封建等级**：写在法律里的身份 | **财产门槛**：写在资格里的数字 |
| 宗教的角色 | 裁决与否定（绝罚） | 记录与暗示（问卦） |
| 普通人能做什么 | **"手头紧"——消极不合作** | **投票，五年一次** |
| 精英能做什么 | 造反、投机、绝罚博弈 | **买席位、买议程、买时间** |
| 谁能推倒最高权力 | 教会（一次绝罚） | **上议院（过半数即可）** |

> **最后两行是这套设定的全部意义。**
> 帝国的不平等是**明的**：你生为农奴，就是农奴。
> 联盟的不平等是**暗的**：你可以投票，但你的票只在两个富人之间选一个，而且**你选出来的人，明天就可能被富人开会赶下来。**
> **而联盟人真心相信自己是自由的——这就是它最厉害的地方。**

## 十一、写作纪律（本章）

1. **联盟的宽容必须是真的，但必须有边界。** 三条女神裂缝已经存在（见 [06](06-宗教与神系.md)），公民权天花板是第四条。
2. **不要写成"民主 vs 专制"。** 联盟是**寡头共和**，帝国是**教权封建**——两边都不是善恶两极，两边都不干净。
3. **数字要具体。** 财产门槛、押金、出资配额，都必须能换算成 09 章的货币。模糊的数字会立刻暴露这套制度是纸做的。
4. **制度要能被玩家利用。** 一个玩家能做的事包括：贿赂下议员、替上议员拉票、在问卦人身上下手、把议案拖到"明年再说"、在法定人数上做算术。**如果这些都不能做，这一章就是废纸。**
