**设计纪律**（12 §一·3、§一·4、§一·5）：

1. **命名禁止「同名＋后缀」**：同一法术线的不同档位必须各有独立名字。
2. **同一系有两个职业时，先写「概念归属表」再写表**：战场级布置归远程施法者；自中场域、冲锋、近战附魔、自我化身归近战职业。
3. **验收方式**：把两职业同环的八条法术并排放，不许有一个概念重复。
4. **自动化检测抓不到「换皮」**：必须人工同环并排比对。
