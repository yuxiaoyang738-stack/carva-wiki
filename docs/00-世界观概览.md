## 需要回答的问题

1. **世界叫什么名字？** 名字里最好藏着一个词根（见 [10 语言与命名](10-语言与命名.md)），让人听到就能猜出一点世界的气质。
2. **六十个字以内，怎么介绍这个世界？** 假设玩家只有一次机会听你描述，你会说什么？
3. **世界的基调三色**：主色、辅色、点色分别是什么？它决定了整个美术方向。
4. **当前时代坐标**：上升 / 鼎盛 / 衰落 / 重建？玩家推开门那一刻，世界正在变好还是变坏？
5. **核心冲突是什么？** 不是"勇者打魔王"，而是"两种都站得住的立场在争夺同一件稀缺之物"。
6. **这台冲突永动机靠什么持续运转？**（见 [01 设计原则](01-设计原则.md) 的三条路径）
7. **玩家是谁？** 天选之人、逐利的冒险者、还是某个组织的新兵？
8. **这个世界最迷人的一个具体画面是什么？** 一句话，能让人立刻想进去看看。

## 草稿区

### 世界名

**卡尔瓦（Carva）** —— 以大陆代称世界。语源：先民语 *kar-wal*，"持守之石"。
一陆三名：帝国称卡尔瓦，西岸称马尔卡，南方称哈瓦尔。详见 [10 语言与命名](10-语言与命名.md)。

### 一句话定位

> 草稿：一个封建帝国、一群自由商港与一片干涸的沙漠，正处在旧秩序裂开的那一代——
> 誓言的重量还在，金钱的重量刚刚出现。

### 基调三色（草案）

| | 色 | 含义 |
|---|---|---|
| 主色 | 石灰与铁锈的**铅灰** | 帝国的秩序、城墙、道路——沉重、耐久、褪色 |
| 辅色 | 港口的**油灯黄** | 商港的金钱、交易、夜里的酒馆与契约 |
| 点色 | 沙与铜的**赭红** | 南方的烈日、旧文明的余烬、香料与血 |

### 当前时代

**中世纪末期**：封建制仍是正统，但正在松动。
- 帝国：皇权、大贵族、教会三方角力，谁也不能独大。
- 联盟：资本萌芽——银行、保险、合股、信用凭证。钱第一次比血统更管用。
- 南方：旧文明已亡，只有商队还记得路。
- **坐标判断**：这是一个"鼎盛期的晚期"——看起来一切如常，实际处处在裂。

### 宗教格局（已定）

| 文明 | 信仰 | 对魔法的态度 |
|---|---|---|
| **帝国** | 唯一主神（名讳不可称，只有"圣印"）。圣光教会 | 一切魔法皆神赐；只承认"恩典"（圣光）；其余皆为异端 |
| **联盟** | 七女神：生命、海洋、暴风、丰饶、审判、勇气、幸运 | 七系各司其职，互不敌对，因此宽容 |
| **南方** | 旧神（未知，伏笔） | 未知 |

> **魔法浓度已定为"中魔"**：成体系、有天赋门槛、**不参与工业与生产**。详见 [07 魔法体系](07-魔法体系.md)。

### 核心冲突（草案 · 尚未确认）

**誓约与契约之争。**（用户尚未拍板，暂存为候选）

封建制的根基是"人对人的誓"（忠诚换保护）；资本主义的根基是"物对物的契约"（金钱换金钱）。
这两套规则在同一个大陆上同时运行，且互相不承认对方的合法性。

- 帝国说：没有誓，就没有秩序。
- 联盟说：没有契约，就没有信用，没有信用就没有一切。
- 教会说：誓是神见证的，契约是人的狡诈。

**另一方已经确定的冲突层**（来自宗教设定）：
**一元 vs 多元**——一个不肯说出名字的神，对七个各有名字的女神。
两边的神学家都在互相定罪，但在同一张桌子上做买卖。

## 七、玩家是谁（P0-5 已定）

### 1. 种族与出身选择

| 选择 | 选项 | 初始影响 |
|---|---|---|
| **种族** | 人类、精灵、矮人、兽人（4 个可玩种族） | 决定初始外观、剪影、种族专属内容、NPC 基础态度 |
| **出身地** | **帝国** / **瓦尔玛同盟** | 决定初始信仰选项、初始声望、新手引导地点、NPC 基础态度 |

### 2. 种族×出身的初始体验差异

| 种族 \ 出身 | **帝国** | **瓦尔玛同盟** |
|---|---|---|
| **人类** | 拥有「公民权」标签：可接官方任务、合法持有土地、参军晋升快；但受教会监管严、异端嫌疑易坐实 | 拥有「商会会籍」标签：跨城邦免税额度、银行贷款利率优惠；但无军籍保护、遭遇海盗/走私需自担风险 |
| **精灵/矮人** | 有居住权无公民权：NPC 态度冷淡/不耐烦，警卫/官员刁难，报酬减少；不可进上议院、不可投票、不可竞选领袖 | 较宽容：允许信仰七女神、可入公会、可买船；但**不得入上议院、不得投票、不得竞选领袖** |
| **兽人** | **南方回流者**（选项 C）：祖辈随大迁徙南迁，主角因商队/使团/逃亡来到北方，初始位于边境城镇；NPC 态度极度敌视，但可通过剧情逐步改变 | 较少见：南方回流商队/使团成员；同盟态度冷淡但无制度性歧视 |

### 3. 阵营流动性

- **出身不锁死阵营**：帝国出身可偷渡至同盟，同盟出身可偷渡至帝国
- **偷渡代价**：金钱/资源/时间/战斗风险 + 目标阵营声望 -200 + 原阵营通缉令
- **改信仰**：原教会任务锁定、神术暂失效、原教会 NPC 态度 -100；新教会从零开始，每次改信仰永久降低「信仰上限」-10%
- **声望三维系统**：
  - **阵营声望**（帝国/同盟/中立）：-1000~+1000，影响 NPC 态度、任务解锁、安全屋、结局分支
  - **信仰虔诚度**（圣光/七女神各系/旧神/无）：0~100%，影响神术/神恩/教会任务/神恩商店
  - **社会声望**（贵族/商会/平民/底层/犯罪）：-500~+500，影响 NPC 基准态度、商店折扣/拒售、队友招募/黑市准入

### 3.5 魅力判定与声望（动态修正）

**所有种族（包括人类）共用同一套魅力修正规则**，区别只在于「种族基础值」。

**总公式**：

> **魅力判定修正 = 种族基础值 + 社会声望修正 + 阵营声望修正**

#### ① 种族基础值（仅与所在地有关）

| 种族 | 在帝国境内 | 在同盟境内 |
|---|---|---|
| **人类** | 0 | 0 |
| **精灵** | **-1** | 0 |
| **矮人** | **-1** | 0 |
| **兽人** | **-1** | 0 |

> 种族基础值不是永久烙印，而是「当地人如何看待你这种族」的起点。在同盟，非人类没有起点惩罚——但这不代表同盟没有隐形天花板（见 [11-西部联盟](11-西部联盟.md) 公民权一节）。

#### ② 社会声望修正（全域生效）

| 社会声望 | 修正 |
|---|---|
| ≥ +300（受尊敬） | **+2** |
| +100 ~ +299（小有名声） | **+1** |
| -99 ~ +99（无名之辈） | **0** |
| -100 ~ -299（名声不佳） | **-1** |
| ≤ -300（恶名昭彰） | **-2** |

#### ③ 阵营声望修正（仅在与该阵营打交道时生效）

| 阵营声望 | 修正 |
|---|---|
| ≥ +500 | **+1** |
| -499 ~ +499 | **0** |
| ≤ -500 | **-1**，且该阵营城邦警卫转为敌对 |

#### 举例

> 一个精灵在帝国某城试图劝说卫兵放行：
> 种族基础 -1，社会声望 +150（+1），对帝国阵营声望 -600（-1）
> → 总计 **-1**。
>
> 同一个精灵在同盟港口和商会谈判：
> 种族基础 0，社会声望 +150（+1），对同盟阵营声望 +600（+1）
> → 总计 **+2**。
>
> **同一个角色，两套世界，两种结果。**

### 4. 信仰与偷渡

| 初始出身 | 初始信仰选项 | 偷渡后可选 |
|---|---|---|
| **帝国** | 仅帝国正教（圣光） | 偷渡至同盟后，可设定「主角实不信圣光」，加入七女神任一教团 |
| **同盟** | 七女神任一 | 偷渡至帝国后，可选择皈依帝国正教 |

### 5. 魔法觉醒机制（新手引导三选一）

主角幼年未显露天赋，未被教会发掘，自认为普通人。**游戏开局不久**，通过以下三选一触发觉醒（玩家选或随机），决定初始 1 环法术、魔法倾向、伏笔分支：

| 选项 | 触发情境 | 觉醒表现 | 伏笔钩子 |
|---|---|---|---|
| **A. 临死爆发** | 遭遇致命袭击（刺杀/怪物/塌方），濒死瞬间本能释放能量护盾/反击 | 护盾/反击的能量形态暗示天赋系别 | 为何「死前」才觉醒？是否有人故意制造险境？ |
| **B. 接触遗物** | 在遗迹/古墓/黑市触碰遗物（圣徽/符文石/蛇人雕像），能量逆流灌入体内 | 遗物共鸣的系别决定初始倾向 | 遗物为何选中主角？背后有何势力布局？ |
| **C. 情绪极致** | 目睹至亲/挚友/无辜者死于眼前，极致愤怒/悲痛触发能量爆发 | 情绪对应的系别（愤怒→火/电，悲痛→生命/水） | 情绪魔法是否可控？主角是否会被情绪反噬？ |

觉醒后，玩家可选择加入初始信仰对应教会，或寻找其他途径学习控制魔法。

### 6. 主角特殊性：A 方案「空容器 / 无因果上限」

| 设定 | 内容 |
|---|---|
| **核心设定** | 主角体内天生缺少「因果锚点」（无因果债上限），能无限燃命/重掷而不爆发，但也无法获得因果庇护——**真正的自由代价是彻底的孤独** |
| **机制解释** | 完美解释「为何主角能无限重掷/燃命不死/因果债不爆发」：主角没有因果上限，只有无限透支的自由 |
| **剧情走向** | 最终揭示：主角是「因果实验」的产物 / 被神明抹去因果的容器<br>最终抉择：接受成为「因果之主」（掌控所有人因果）还是销毁自己归还世界因果平衡 |
| **机制呼应** | 完美解释「为何主角能无限重掷/燃命不死/因果债不爆发」——**因为主角没有因果上限，只有无限透支的自由** |
